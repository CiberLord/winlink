# WinLink

PowerShell и файлы Windows с Mac по HTTPS. Windows-агент запускается через Node.js 22 или новее в твоём профиле и работает, пока открыто окно терминала.

## Первый запуск

Подключи Mac и Windows к одной Wi‑Fi сети. Нужны Node.js 22 или новее на обеих машинах.

**На Windows** открой обычный PowerShell в папке репозитория и передай IPv4-адрес Mac. Например:

```powershell
.\setup.cmd 192.168.1.42
```

При первом запуске команда установит JS-зависимость и запросит UAC для правила брандмауэра. Правило разрешает TCP-порт 48766 для Node.js с IP Mac. После этого запустится агент с правами того PowerShell, из которого ты вызвал `setup.cmd`. Оставь окно открытым.

**На Mac** выполни из папки репозитория:

```bash
npm ci
npm run build
node dist/cli.js pair 192.168.1.50
```

Подставь IP из окна WinLink на Windows. Сверь `Windows certificate code` на экранах. Если совпадает, введи `y` на Mac, затем восьмизначный `Pairing PIN` с Windows. PIN действует 10 минут. После успешной привязки Mac сохранит профиль и сможет подключаться, пока агент запущен.

## Команды на Mac

```bash
node dist/cli.js doctor --json
node dist/cli.js exec --json 'Get-Location'
node dist/cli.js ls --json 'C:\Games\Elden Ring\Mods'
node dist/cli.js get 'C:\Games\Elden Ring\Mods\mod.zip' ./mod.zip
node dist/cli.js put ./mod.zip 'C:\Games\Elden Ring\Mods\new-mod.zip'
```

Codex может вызывать эти команды из терминала. `exec` возвращает stdout, stderr и код завершения. Команды принимают `--timeout` в секундах. Передача идёт через временный файл, существующие файлы сохраняются. Для загрузок выбирай диск Windows с поддержкой жёстких ссылок, например NTFS.

## Перезапуск и диагностика

- Чтобы остановить агент, нажми **Ctrl+C** в его окне на Windows. Чтобы запустить снова, повтори `setup.cmd` с тем же IP Mac. Сохранённая привязка продолжит работать.
- Чтобы получить новый PIN или привязать другой Mac, перезапусти агент с `-PairAgain`. Новая привязка заменяет предыдущую.
- Если изменился IP Windows, запусти агент с `-PairAgain` и привяжись к новому адресу. Если изменился IP Mac или путь до Node.js, установщик обновит правило брандмауэра.
- Если `doctor` сообщает о тайм-ауте и агент запущен, проверь адрес Windows в его окне и общую Wi‑Fi сеть. Для повторной настройки правила останови агент и запусти `setup.cmd` с `-OpenFirewall`.
- Профиль Mac находится в `~/.winlink/https_profile.json`. Диагностика команд хранится в `~/.winlink/operations.jsonl`. Агент Windows хранит сертификат и хеш токена в `%LOCALAPPDATA%\WinLink`.

## Как устроено подключение

Агент принимает запросы с выбранного IP Mac. При привязке пользователь сверяет отпечаток сертификата Windows. PIN и токен передаются по TLS только после этой проверки. Клиент сохраняет полный сертификат и проверяет его при каждом запросе. Команды PowerShell и файлы доступны по токену.

Для подключения через приватный VPN потребуется выбрать его интерфейс при запуске агента. API и проверка сертификата уже отделены от выбора сетевого интерфейса.

## Проверка

```bash
npm ci
npm test
```

CI запускает HTTPS, авторизацию и передачу файлов на macOS и Windows. На Windows тест также запускает `setup.cmd` на loopback и выполняет PowerShell через API.
